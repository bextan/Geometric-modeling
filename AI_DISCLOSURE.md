### 🛠️ Integration & Debugging Log (Interfacing Self-Written Engine with AI Visuals)

Because the core geometric engine was authored independently while the graphical interface was generated using ChatGPT, significant engineering effort went into interfacing and debugging the visual rendering pipeline:

### 1. Connecting Self-Written Half-Edge Data to Viewport Buffers
* **Challenge**: The ChatGPT-generated visualizer expected flat coordinate/index buffers, whereas the self-written algorithm pipeline maintained rich half-edge topological adjacencies.
* **Engineering Solution**: Developed a clean data adapter in `ui/` that extracts coordinate and normal arrays from the internal mesh structure to feed into the rendering pipeline without altering core geometric structures.

### 2. Real-Time Visual Refresh During Subdivision
* **Challenge**: ChatGPT's initial UI rendering loop retained cached vertex buffers, which either froze the display or failed to update the visual canvas when a subdivision step was triggered.
* **Engineering Solution**: Restructured the UI draw loop to rebind vertex buffer objects (VBOs) and refresh vertex counts dynamically whenever `Space` or `S` triggers a Loop or Butterfly iteration.

### 3. Wireframe vs. Shaded Face Normal Alignment
* **Challenge**: The visual wireframe toggle generated by ChatGPT produced backface culling artifacts and visual z-fighting on complex imported OBJ models.
* **Engineering Solution**: Adjusted OpenGL polygon offset states (`glPolygonOffset`) and depth buffer testing in the rendering loop to ensure clean visual separation between wireframe edges and shaded faces.
